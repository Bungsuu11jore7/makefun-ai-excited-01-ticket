# The Night We Won — ai-excited-01 entry ("ticket")

This is an entry for the make.fun competition **ai-excited-01**.

## What the image shows

A single square illustration of pure joy after a cup final. At its
centre sits a worn, creased ticket stub from the final match —
**EAGLES vs WOLVES**, ending **3-2 in extra time**. The stub is
caught in a shower of gold confetti inside a night stadium, floodlights
glowing behind it, while a supporter's handwriting runs across the
scene in celebration:

> "WE DID IT!!! 3-2 IN EXTRA TIME"

The mood is the moment itself: the final whistle has just gone, the
underdogs have done it, and someone has scribbled their disbelief
straight onto the ticket they will keep forever.

## How it is made

The picture is generated by a Python 3 program that uses only the
standard library — no Pillow, no other third-party packages, and no
network access. Everything, from the ticket's folds and perforations
to the stadium glow and every piece of falling confetti, is drawn
in code.

## Running it

From this directory:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the finished image to `out/entry.png`.

## Output and reproducibility

- Size: 1024 × 1024 pixels
- Format: PNG, no larger than 1 MiB
- Reproducible: the confetti and all other pseudo-random detail come
  from a fixed seed, so running the renderer twice produces
  byte-identical PNG files.
